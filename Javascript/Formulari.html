Repaso HTML

Titulos

Los titulos se hacen con las etiquetas h1, h2, h3, h4 hasta h6. H1 es el titulo de primer nivel y el mas grande

Párrafos

Los parrafos se hacen con la etiqueta P. Para hacer saltos de linea, utilizamos la etiqueta BR.

Enlaces

Los enlaces o hipervinculos nos permiten abrir otra pagina web

Para hacer un enlace utlizamos A.

Enlace a Youtube: pincha aqui

Imagenes

Para insertar una imagen utilizamos la etiqueta img. Puede ser una imagen en mi ordenador o de Internet.

Formatos

Podemos cambiar el formato del texto con b, u, i

Esto esta en negrita, subrayado, y cursiva

Podemos combinar estilos: Asi

Estilos

Para dar estilos al contenido de una etiqueta usamos el atributo style.

Esto saldrá de color azul

Esto saldrá mas grande

Las listas se hacen con las etiquetas ul, ol, y li

Elaboración

  1. En un bol ponemos la harina
  2. Añadimos el agua y la levadura
  3. Mezclamos y vamos echando aceite
  4. Amasamos y hacemos una bola
  5. La dejamos reposar una hora
  6. La extendemos
  7. Ponemos el tomate, el queso y la albahaca
  8. Horneamos entre 7 y 12 minutos a 250 grados
